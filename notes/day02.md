## What I Learned

- **1. Integer Division (`//`) & Modulo (`%`)**
  - **Persian:** نحوه استفاده از `//` برای محاسبه خارج‌قسمت بدون اعشار و `%` برای به‌دست آوردن باقی‌مانده تقسیم جهت تبدیل ثانیه به ساعت، دقیقه و ثانیه.
  - **English:** How to use `//` for integer division and `%` for modulo to convert seconds into hours, minutes, and seconds.

- **2. String Processing Methods**
  - **Persian:** کاربرد متدهای `lower()`، `upper()` و `strip()` برای تمیزکاری ورودی‌های کاربر و استانداردسازی ساخت یوزرنیم.
  - **English:** Using `lower()`, `upper()`, and `strip()` methods to clean user inputs and standardize username generation.

- **3. Conditional Logic & Thresholds**
  - **Persian:** استفاده از ساختار `if/else` برای محاسبه حقوق نهایی با اضافه کاری و تعیین تخفیف فاکتور بر اساس آستانه مشخص (Threshold).
  - **English:** Using `if/else` logic to calculate final salaries with overtime and apply shopping receipt discounts based on predefined thresholds.
